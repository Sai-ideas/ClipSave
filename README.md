# 剪存

剪存是原生 Android 剪貼簿管理工具，支援 Android 10 及以上版本。它以 Clipboard Companion 的公開功能為參考，使用獨立介面與本機儲存。

## 使用方式

- 剪存可收錄文字、網址與圖片。在其他 App 選取文字後，可在系統選單選「存到剪存」。也可以用系統分享、在剪存按「儲存目前剪貼簿」、新增文字或從檔案選擇器匯入圖片。
- 透過類型、收藏、文字、檔名或標籤找剪輯。文字和連結可按「編輯」修改內容，原有的儲存時間、置頂、收藏、標籤和私密設定會保留。選「更多」可整理、分享或刪除剪輯。網址可加入待讀，待讀期間暫緩過期清理，標為已讀後恢復一般保留規則。既有 PDF 仍可預覽首頁、複製及分享。
- 介面會跟隨 Android 系統的淺色或深色模式。
- 在隱私設定調整保留期限或啟用離開時上鎖。預設保留 30 天。置頂項目保留至手動刪除，收藏項目仍遵守保留期限。過期資料會在剪存處理資料庫時清理。

## 組成文章

- 從首頁開啟「草稿」，新增文章後可插入文字、網址或圖片剪輯，並補上新段落和小標。長按區塊的「排序」可拖曳，點按則可選上移或下移。
- 草稿保存卡片副本。修改草稿文字、清理歷史清單或等來源剪輯到期，草稿內容都會保留。草稿含有私密剪輯時，整篇會保護起來，重新開啟須驗證。
- 「預覽全文」可看見整篇文章與圖片。「複製全文」會複製文字並以檔名標示圖片位置。「匯出 ZIP」會把 `article.md` 與圖片一起寫到你選定的位置，供解壓後發布。這是文章匯出，檔案內的 Markdown 和圖片可直接讀取。

## 隱私設計

- 剪輯內容、標籤、檔名與附件使用 Android Keystore 管理的 AES-256-GCM 金鑰加密，儲存在 App 私有目錄。關閉 Android 備份與裝置移轉，App 未宣告網路、無障礙服務或廣泛檔案權限。
- 儲存由使用者確認。Android 標記為敏感的剪貼簿內容會自動設為私密，也可手動標記。私密剪輯的內容、檔名及標籤會從清單和搜尋中隱藏。
- 每次查看、編輯、複製、分享或變更私密設定時，系統會要求驗證已註冊的生物特徵，例如指紋，或使用裝置的 PIN、密碼或圖案。可用方式依裝置設定而定。取消驗證會維持遮罩。主畫面及對話框使用系統的安全視窗旗標。
- 選用的 App 鎖使用系統螢幕鎖定憑證保護畫面。儲存加密持續啟用。個別附件由 Android 授予接收 App 讀取權限，複製或分享後，接收方可自行保留資料。選取系統上的雲端檔案時，檔案提供者可自行下載來源檔案。
- Android 10 起限制非前景 App 讀取剪貼簿。剪存在使用者按下按鈕時讀取當前剪貼簿。每次可收錄一則文字、網址或一張圖片。文字上限 20,000 個字元，附件上限 16 MiB，歷史清單最多 200 筆，剪輯與草稿共用 96 MiB 附件空間。

參考 [Clipboard Companion 商店頁](https://play.google.com/store/apps/details?id=com.vinsontech.clipboardcompanion) 與 [Android 剪貼簿存取限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)。

## 建置與安裝

用 Android Studio 開啟本資料夾，使用 JDK 17 和 Android SDK Platform 35。也可以使用 Gradle Wrapper 建置開發版。

```sh
./gradlew :app:assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

隨附的試用 APK 使用這次建置的開發簽章。本機重建時 Gradle 會使用你的開發簽章。若以不同簽章替換同套件的試用版，Android 要求先解除安裝，裝置上的剪存資料也會隨之刪除。
