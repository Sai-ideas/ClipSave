# 剪存

剪存是原生 Android 剪貼簿管理工具，支援 Android 10 及以上版本。它以 Clipboard Companion 的公開功能為參考，使用獨立介面與本機儲存。

## 使用方式

- 剪存可收錄文字、網址與圖片。在其他 App 選取文字後，可在系統選單選「存到剪存」。也可以用系統分享、在剪存按「儲存目前剪貼簿」、新增文字或從檔案選擇器匯入圖片。
- 透過類型、收藏、文字、檔名或標籤找剪輯。文字和連結可按「編輯」修改內容，原有的儲存時間、置頂、收藏、標籤和私密設定會保留。選「更多」可整理、分享或刪除剪輯。網址可加入待讀，待讀期間暫緩過期清理，標為已讀後恢復一般保留規則。既有 PDF 仍可預覽首頁、複製及分享。
- 介面會跟隨 Android 系統的淺色或深色模式。
- 在隱私設定調整保留期限或啟用離開時上鎖。預設保留 30 天。置頂項目保留至手動刪除，收藏項目仍遵守保留期限。過期資料會在剪存處理資料庫時清理。

## 組成文章

- 從首頁開啟「拼報」，新增文章後可插入文字、網址或圖片剪輯。從區塊的「排序」把手直接上下拖曳可調整順序，高亮線顯示放開後的插入位置，拖近畫面邊緣時會捲動。點按把手也可選上移或下移。
- 頂部文字工具列固定，切換「精簡／詳細」時位置一致。詳細模式長按卡片類型或串聯標題，等標題變白後可拖曳排序。長按卡片正文可多選。編輯與刪除在卡片表頭的「選項」。
- 以表頭的三角符號摺疊或展開卡片及串聯。卡片摺疊時最多顯示三行文字。精簡模式會收起表頭，可點卡片正文切換展開狀態，或從「展開串聯」打開已摺疊的串聯。每張卡片與串聯各自記住最後狀態。
- 底部固定的「剪輯／拼報」可往返兩區。切回拼報可回到原文件與閱讀位置，私密拼報仍需要驗證。
- 長按卡片進入多選，可批次移除卡片或將至少兩張未串聯的卡片組成串聯。卡片會集中到最上方的選取位置，保留原本順序。可拖曳標題搬移整組，也可在組內排序。從串聯選單改標題、改色或解除串聯。全文輸出依照卡片的當前順序。
- 「新增區塊」提供一般段落、小標、Setext 標題（`===`）、分隔線、引用、項目清單、編號清單、待辦清單和程式碼。這些格式會寫入匯出的 Markdown。待辦清單每行一項，會略過空白列並去除每列外側空白。可貼上 `- [x] 任務` 保留勾選狀態，或以反斜線開頭（如 `\[x]`）將前置符號保留為原文。
- 「插入剪輯」與「新增區塊」使用相同的卡片式面板。插入時數字代表點選順序，確認後會將整批加到拼報末尾。取消選取後再選會排到最後。若批次含私密剪輯，只需驗證一次。
- 文字或網址卡片與來源剪輯內容不同時，可從卡片的「選項 → 從剪輯更新」比較後替換拼報副本。串聯改色提供常用色票與自訂滑桿，確認套用後才儲存。
- 拼報保存卡片副本。來源剪輯被刪除或到期時，副本與其私密狀態都會保留。可在「拼報設定」開啟或關閉手動保護，兩種操作都使用裝置驗證。手動保護開啟或拼報仍有私密卡片時，開啟前須驗證。移除最後一張私密卡片後，是否需要驗證由手動保護設定決定。舊版私密拼報無法辨識個別來源的私密狀態時，會繼續保護其中從剪輯插入的區塊。
- 可從拼報清單或編輯頁的「拼報設定」刪除整份拼報，來源剪輯會保留。刪除私密拼報前須先驗證。
- 「預覽全文」可看見整篇文章與圖片。「複製全文」會複製文字並以檔名標示圖片位置。「匯出 ZIP」會把 `article.md` 與圖片一起寫到你選定的位置，供解壓後發布。這是文章匯出，檔案內的 Markdown 和圖片可直接讀取。

## 隱私設計

- 剪輯內容、標籤、檔名與附件使用 Android Keystore 管理的 AES-256-GCM 金鑰加密，儲存在 App 私有目錄。關閉 Android 備份與裝置移轉，App 未宣告網路、無障礙服務或廣泛檔案權限。
- 儲存由使用者確認。Android 標記為敏感的剪貼簿內容會自動設為私密，也可手動標記。已儲存的剪輯可從「更多」設為私密，同步保護拼報內的副本。轉換是單向的。私密剪輯可填寫「顯示描述」，在驗證前用來辨認卡片。留空時顯示 `****`。原文、檔名及標籤會從清單和搜尋隱藏。之後可在「更多 → 整理剪輯」驗證後修改或清空描述。
- 每次查看、編輯、複製、分享或變更私密設定時，系統會要求驗證已註冊的生物特徵，例如指紋，或使用裝置的 PIN、密碼或圖案。可用方式依裝置設定而定。取消驗證會維持遮罩。主畫面及對話框使用系統的安全視窗旗標。
- 選用的 App 鎖使用系統螢幕鎖定憑證保護畫面。儲存加密持續啟用。個別附件由 Android 授予接收 App 讀取權限，複製或分享後，接收方可自行保留資料。選取系統上的雲端檔案時，檔案提供者可自行下載來源檔案。
- Android 10 起限制非前景 App 讀取剪貼簿。剪存在使用者按下按鈕時讀取當前剪貼簿。每次可收錄一則文字、網址或一張圖片。文字上限 20,000 個字元，附件上限 16 MiB，歷史清單最多 200 筆，剪輯與拼報共用 96 MiB 附件空間。

參考 [Clipboard Companion 商店頁](https://play.google.com/store/apps/details?id=com.vinsontech.clipboardcompanion) 與 [Android 剪貼簿存取限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)。

## 建置與安裝

用 Android Studio 開啟本資料夾，使用 JDK 17 和 Android SDK Platform 35。也可以使用 Gradle Wrapper 建置開發版。

```sh
./gradlew :app:assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

隨附的試用 APK 使用這次建置的開發簽章。本機重建時 Gradle 會使用你的開發簽章。若以不同簽章替換同套件的試用版，Android 要求先解除安裝，裝置上的剪存資料也會隨之刪除。

## 拼報回歸測試

在已解鎖的 Android 測試裝置上關閉剪存的 App 鎖，安裝同一簽章的開發版及測試套件，執行下列指令。

```sh
./gradlew :app:installDebug :app:installDebugAndroidTest
adb shell am instrument -w dev.local.clipvault.test/dev.local.clipvault.PinbaoRegression
```

測試建立獨立的臨時剪輯與拼報，涵蓋待辦內容、私密副本、手動保護、固定工具列、多選與真實觸控拖曳。可變更測試裝置的顯示大小與字型大小後重跑。
